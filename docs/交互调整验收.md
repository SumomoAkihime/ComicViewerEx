# 侧栏与阅读交互回归检查表

状态：v1.1.0 已完成 Release 编译、核心测试 4/4、画布／标签及侧栏／列表自动验收。下列为完整检查范围，并非全部通过清单；实际通过项和证据见根目录《验收报告》。

本次实测包括 200% DPI 停靠／宽度／重启恢复、目录 Enter／Esc、画布手势、列表上下键与焦点、多标签与独立页签、单行气泡高度和点击筛选、全局双页切书与重启。其他 DPI、复杂多选、外部点击及加载中连续模式切换等仍待补充。

## 布局与目录

- 拖标题到左右边缘后停靠，拖到其他位置不切换；分隔线两侧都可调宽，最小 280 DIP，画布最小 320 DIP。
- 窄侧栏按钮换行且可点击；在 100%、150%、200% 缩放及跨屏 DPI 变化下检查字体、最小窗口和控件遮挡。
- 退出重启恢复方向与宽度；全屏往返恢复侧栏，目录弹窗不会遗留在屏幕上。
- 下拉树展开箭头只展开；鼠标点击名称或 Enter 确认目录并收起，Esc、外部点击或切换应用取消。
- 中文路径、空目录、不可访问目录正常提示，不破坏已有列表或画布。

## 画布与列表

- 点击画布左右半边（包括留白）分别上一页／下一页；切换阅读方向后保持此规则。
- 轻微移动仍为点击，超过系统阈值后平移且松开不翻页；取消鼠标捕获不会误翻页。
- 左键双击翻两次页且不全屏；中键、F11 和按钮切换全屏，Esc 退出。
- 单击文件即打开，上下键与按键连发可连续切书；首尾不越界，同一本不重复解压。
- Ctrl/Shift 多选、点击空白、程序恢复选择、刷新列表都不意外打开文件；批量打标仍可用。
- 从递归筛选列表切换到子目录里的漫画后，目录范围、筛选、滚动位置和列表焦点保持。
- 快速交替选择普通、固实或加密漫画，只显示最终请求；密码取消和错误后仍能选择其他漫画。

## 全局偏好

- A、B 两本旧数据具有不同模式、方向和适应方式时，交替打开仍沿用全局选择，各自进度与缩放倍数正确恢复。
- 尚未打开漫画时可以改变开关；第一次打开及重启后生效。
- 初次升级从上次书籍迁移；上次文件已删除仍可从数据库迁移；没有记录时采用默认值。
- 打开期间连续切换单页／双页／分页，最终图像与开关一致；翻页解码期间修改方向、适应方式或缩放不会被旧结果覆盖。
- 宽图分页的前后半页可以恢复；改成其他模式后不带入半页位置。
- 数据库只读时明确报错，不出现开关已保存的假象。

## 多标签与气泡

- 同一文件添加至少三个标签，重复添加不重复、不覆盖；移除其中一个后，其余标签保持。标签名称含逗号、空格时气泡不得错误拆分。
- “筛选”页签多个勾选即时生效；全部／任一匹配、递归范围和清除筛选正常。切到“打标”页签勾选标签不会筛掉待操作文件。
- 多文件批量添加／移除只影响勾选标签；两个页签的勾选独立保存，清除筛选不会重置打标勾选。
- 底部随文件选择更新；多选明确显示数量和焦点文件，没有列表选择时回退为正在阅读文件。未打标文件显示“暂无标签”。
- Ctrl 取消选择至只剩一个文件时，即使焦点仍在未选中的行，气泡也显示唯一选中文件；滚动气泡后重新点击不得因获得焦点而跳动或点错标签。
- 气泡点击与键盘激活可加入／取消筛选，高亮与筛选页签一致；不覆盖其他筛选条件。重命名、删除或批量改标签后同步更新。
- 大量／长标签在固定单行高度内滚动，不能挤占更多画布；滚动后点击命中对应标签，改变窗口宽度、DPI 和全屏往返后仍可用。
